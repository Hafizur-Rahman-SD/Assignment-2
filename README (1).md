# TechWave - Podcast Website

## 🎙️ Project Overview

TechWave is a modern, fully responsive podcast website built with HTML5 and CSS3. The website showcases a technology podcast platform with multiple sections including hero banner, about, features, episodes, and host information.

## ✨ Features Implemented

### ✅ Main Requirements (50 Marks)

#### Navbar
- **Desktop/Laptop/Large Device:**
  - Logo positioned on the left side
  - Navigation menu items centered (Home, About, Episodes, Contact)
  - Gradient subscribe button on the right
  - Smooth hover effects and transitions

- **Mobile Device:**
  - Hamburger menu icon for navigation
  - Responsive hidden navigation with slide-in effect
  - Full-width mobile menu layout

#### Banner Section
- **Desktop/Laptop/Large Device:**
  - Full-width background image
  - Center-aligned podcast circle with floating animation
  - "New" badge positioned on podcast circle
  - Compelling heading and descriptive text
  - Two call-to-action buttons (Listen Now, Browse Episodes)

- **Mobile Device:**
  - Responsive layout with adjusted image sizes
  - Stacked button layout
  - Optimized text sizing for readability

#### About Section
- **Desktop/Laptop/Large Device:**
  - Section heading with descriptive introduction
  - 4 statistics displayed in a row (Active Listeners, Episodes, Countries, Platforms)
  - Icon-based design with hover effects
  - Clean card layout with shadows

- **Mobile Device:**
  - 2x2 grid layout for statistics
  - Touch-optimized card sizes
  - Maintained visual hierarchy

#### Why Choose Section
- **Desktop/Laptop/Large Device:**
  - 5 feature cards in 3-2 grid layout
  - Each card contains icon, title, and description
  - Hover animations and visual effects
  - Consistent spacing and alignment

- **Mobile Device:**
  - Single column layout
  - Full-width feature cards
  - Optimized card padding

#### Featured Episodes Section
- **Desktop/Laptop/Large Device:**
  - 3 episode cards in row layout
  - YouTube video embeds
  - Episode title, description, and duration
  - Card hover effects

- **Mobile Device:**
  - Single column stacked layout
  - Responsive video embeds
  - Consistent card styling

#### Footer Section
- **Desktop/Laptop/Large Device:**
  - Background image with overlay
  - Centered brand and platform information
  - Platform icons (Spotify, Apple Podcasts, YouTube)
  - Copyright text with horizontal divider

- **Mobile Device:**
  - Responsive centered layout
  - Optimized icon sizes
  - Maintained readability

- **Medium Device:** 577px to 992px (handled by base styles)

## 🎨 Design Features

### Color Scheme
- Primary: Purple gradient (#6C5CE7 to #764BA2)
- Accent: Red (#FF6B6B) and Teal (#4ECDC4)
- Text: Dark gray (#2D3436) for primary, Medium gray (#636E72) for secondary
- Background: White (#FFFFFF) and Light gray (#F8F9FA)

### Typography
- Headings: Bold, large sizes with proper hierarchy
- Body: 16px base with 1.6 line height for readability
- All text is meaningful and relevant to tech podcasting

### Animations
- Floating effect on podcast circle
- Pulse animation on "New" badge
- Smooth hover transitions on all interactive elements
- Card lift effects on hover
- Fade-in animations on scroll (desktop)

### Accessibility
- Semantic HTML5 elements
- Proper heading hierarchy
- Alt text on all images
- Sufficient color contrast
- Focus visible styles
- Touch-friendly tap targets (minimum 44px)
